# Govt Exam Old Papers Portal

राजस्थान (RPSC, RSSB), केंद्र सरकार (SSC, UPSC, Railway), और बैंक व बीमा (IBPS, SBI, LIC) भर्ती परीक्षाओं के पिछले वर्षों के पेपर्स और आंसर की का पोर्टल।

## फाइल्स की जानकारी:
- `index.html`: वेबसाइट का मुख्य फ्रंटएंड (सर्च बार, फ़िल्टर और रिस्पॉन्सिव डिज़ाइन)।
- `papers.json`: डेटाबेस जहाँ सभी पेपर्स का डेटा सेव रहता है।
- `auto_updater.py`: Python ऑटोमेशन स्क्रिप्ट जो नए पेपर्स को ऑटोमैटिक स्क्रैप करके `papers.json` में जोड़ती है।
- `.github/workflows/update.yml`: GitHub Actions फाइल जो रोज़ाना ऑटो-अपडेटर को चलाती है।

## GitHub पर कैसे अपलोड करें:
1. इस ज़िप फाइल को अपने कंप्यूटर/फ़ोन में एक्सट्रैक्ट (Unzip) करें।
2. GitHub पर अपनी रिपॉजिटरी में जाएँ।
3. `Add file` -> `Upload files` पर क्लिक करके इन सभी फाइल्स को अपलोड कर दें।
4. `Settings` -> `Pages` में जाकर Branch को `main` चुनकर Save करें।
